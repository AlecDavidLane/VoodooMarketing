02 · CORE OFFERINGS

Ambitious creative ideas, built
as production-ready systems.

Voodoo transforms ambitious creative ideas into reliable, production-ready systems that last for years. We don't just make prototypes — we build solutions that actually work.

CORE · 01

System Design

We design the whole system before writing any code — deciding where hardware goes, how components communicate, how data flows, and identifying potential bottlenecks or failure points early on.

Our clients never have to worry about system architecture. We handle the tough technical decisions upfront, preventing costly problems down the road.

CORE · 02

Software Development

We write robust, production-quality code using modern technologies like Electron, Node.js, Python, FastAPI, and the latest AI tools. This isn't just code that works when conditions are perfect — it's real software with thorough error handling, logging, and testing, built to perform reliably for years, even in front of paying customers.

CORE · 03

Automated Deployment

We ensure every installation is reproducible. Any machine we deploy can be rebuilt from scratch in just hours, not days. All configurations are version-controlled, updates can be pushed remotely, and hardware swaps are quick and seamless.

When something does need updating, it can usually be done remotely — without sending an engineer to site.

WHAT'S UNIQUE

Infrastructure
as code.

Every venue we ship runs on Voodoo Deploy — every machine, every show-control config, every content pack declared in source. Nothing is hand-tuned. Nothing is undocumented.

That foundation unlocks three things off-the-shelf integrators can't offer.

voodoo-deploy · venue.yaml
DECLARATIVE 
# A whole venue, in version control:
venue:      norwich-01
machines:
  - role:     show-server
    image:    show-server:v2.1.4
  - role:     content-player
    replicas: 4
remote:     av-teleport://norwich-01
01
Infrastructure as code

Every machine, every cue, every config lives in a Git repository. The venue is reproducible from source — review it, diff it, roll back to last week's known-good state in one command.

02
Automated machine deployment

Bare-metal to running show in under an hour. Provision one machine or a hundred from the same source of truth — every box comes up identical, every time, with no manual install steps.

03
Secure remote access

AV Teleport tunnels every venue to a single operations plane — encrypted, audit-logged, no exposed inbound ports. Push updates, diagnose faults and ship content overnight from anywhere.
